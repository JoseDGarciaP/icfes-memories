# ICFES Memories

Plataforma para prepararse para la prueba **Saber 11** practicando con preguntas reales liberadas por el ICFES.

## Objetivo

Que cualquier estudiante pueda entrenar para el examen desde el celular o el computador, de forma gratuita, con preguntas de años anteriores. Así se familiariza con el formato y los tipos de pregunta, y sabe en qué áreas necesita reforzar.

## Qué ofrece

- Práctica por área: Lectura Crítica, Matemáticas, Sociales y Ciudadanas, Ciencias Naturales e Inglés.
- Simulacros con tiempo, parecidos a la prueba real.
- Resultados al terminar, con la respuesta correcta de cada pregunta.
- Funciona sin internet y se puede instalar en el celular como una app.
- Modo claro y modo oscuro.

## Estado

En desarrollo. Las preguntas provienen de cuadernillos liberados por el ICFES y se usan con fines educativos.
